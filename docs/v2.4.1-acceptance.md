# Portfólio 2.4.1 — matriz de aceite

| Área             | Critério                                                                                                       | Validação                 |
| ---------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------- |
| Status técnico   | Nenhum grupo vazio é renderizado                                                                               | Playwright dedicado       |
| SintegraPro      | Duas colunas equilibradas e sem placeholder visual                                                             | snapshot + inspeção       |
| Grid             | Uma, duas ou três colunas conforme grupos disponíveis                                                          | CSS responsivo + DOM      |
| Hero mobile      | Retrato não prejudica os CTAs; botão secundário permanece legível                                              | snapshots 360, 390 e 430  |
| Captura          | Intro, animações e rolagem suave desativadas                                                                   | `data-capture`            |
| Cobertura        | Hero, manifesto, capacidades, trilho, quatro cases, Labs, trajetória, competências, formação, contato e rodapé | manifesto da captura      |
| Duplicação       | Nenhuma captura igual ou perceptualmente quase idêntica                                                        | SHA-256 + hash perceptual |
| Evidência mobile | Vídeo WebM e trace Playwright contínuos                                                                        | `npm run capture:qa`      |
| Responsividade   | Sem overflow nas sete resoluções oficiais                                                                      | Playwright visual         |
| Acessibilidade   | Nenhuma violação axe séria ou crítica                                                                          | axe-core                  |
| Qualidade        | Prettier, TypeScript, ESLint, links, imagens e builds aprovados                                                | comandos oficiais         |

## Comandos oficiais

```bash
npm ci
npm run quality
npm run test:visual
npm run build:sites
npm run capture:qa
npm audit --omit=dev
```

## Resultado da validação

- `npm run quality`: aprovado (Prettier, TypeScript, ESLint, imagens, GitHub Pages e links internos).
- `npm run test:visual`: 17 testes aprovados nas sete resoluções.
- Axe: nenhuma violação séria ou crítica.
- `npm run build:sites`: aprovado; três rotas pré-renderizadas.
- `npm audit --omit=dev`: zero vulnerabilidades de produção.
- PT/EN, Experiência/Profissional, movimento reduzido, zoom de 125%, menu, lightbox, contato e rodapé: aprovados.
- SintegraPro: dois grupos e duas colunas, sem painel vazio.
- Capture QA: 14 capturas desktop e 14 mobile, todas as seções presentes, sem duplicações exatas ou perceptualmente próximas.
- Evidência contínua: vídeo WebM e trace Playwright gerados em `tmp/capture-qa/mobile-evidence/`.
