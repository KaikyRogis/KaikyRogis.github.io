# Portfólio 2.1 — matriz de aceite

Fonte: documento “Temos algumas melhorias”, recebido em 31/07/2026.

| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------- |
| 1. Tradução incompleta         | Seletor removido. O site permanece integralmente em português até existir uma rota `/en/` completa.                                                                      | Não existe controle de idioma ou conteúdo parcial em inglês.    |
| 2. Informações perecíveis      | Stage usa “Setembro de 2024 — Presente”; rodapé e terminal usam “Portfolio version 2.1”, sem data ou duração fixa.                                                       | Busca automática por textos antigos.                            |

| 6. Contato                     | `mailto:` recebe aviso explícito e fallback “Copiar mensagem”; WhatsApp e telefone pessoal permanecem ausentes.                                                          | Validação do formulário, clipboard e varredura por número/link. |
| 7. Starter                     | Drizzle, D1, schemas, exemplos, autenticação de starter, ícones genéricos e dependências associadas removidos.                                                           | Árvore e dependências auditadas.                                |
| 7. Sites mínimo                | `.openai`, Vinext, Vite, Worker e Cloudflare foram mantidos porque sustentam a cópia privada de revisão em produção; não são código morto.                               | `build:sites` e deploy privado.                                 |
| 8. Componentização             | Header, cursor, terminal, paleta, formulário, dados e hook de foco foram extraídos. CSS foi formatado no código-fonte.                                                   | ESLint, Prettier e TypeScript.                                  |
| 9. Tipografia pequena          | Labels informativos usam no mínimo 11 px e `line-height: 1.4`; tamanhos menores ficam decorativos.                                                                       | Inspeção CSS e auditoria visual.                                |
| 10. Acessibilidade de diálogos | Foco preso, retorno ao acionador, bloqueio de rolagem, Escape, `aria-live`, `aria-expanded`, `aria-pressed` e camada ativa. Header e link de salto ficam fora do `main`. | axe, teclado e inspeção DOM.                                    |
| 11. Redução de movimento       | `MotionConfig`, Motion condicional, GSAP/cena/intro/CSS desligáveis e hover removido quando desativado.                                                                  | Preferência reduzida e controle manual.                         |
| 12. Imagens                    | Retrato e screenshots convertidos para WebP; OG quantizado; dimensões explícitas; galeria lazy; retrato preload; 3D iniciado em idle.                                    | Tamanho dos ativos, rede e Lighthouse.                          |
| 13. SEO                        | `affiliation` substitui `alumniOf`; Open Graph recebe `url` e `siteName`.                                                                                                | HTML estático e dados estruturados.                             |
| 14. GitHub                     | README do perfil, preview, arquitetura, Homepage, Topics, licença e descrição profissional. Repositórios principais fixados quando a permissão da conta permitir.        | API/CLI e perfil público.                                       |
| WhatsApp pessoal               | Botão e link de contato pessoal permanecem ausentes. O case técnico foi renomeado corretamente para OmniChat.                                                            | Varredura de fonte e links.                                     |

## Resultado da verificação

- `prettier --check`, `tsc --noEmit`, ESLint e `next build`: aprovados.
- Auditoria npm das dependências de produção: 0 vulnerabilidades.
- axe-core sobre o HTML exportado (WCAG 2 A/AA e 2.1 AA): 0 violações, 20 regras aprovadas.
- Testes de interface em desktop e 390 × 844 px: sem overflow horizontal; busca, teclado, retorno de foco, menu e controles móveis aprovados.
- `vinext build`: todas as cinco etapas, pré-renderização e geração do servidor concluídas; no Windows, o processo encerra depois do sucesso por uma asserção nativa conhecida do runtime.

## Comandos de aceite

- `npm run typecheck`
- `npm run lint`
- `npm run format:check`
- `npm run build`
- `npm run build:sites`
- Lighthouse nas categorias Performance, Accessibility, Best Practices e SEO
- axe sem violações críticas ou sérias
- QA desktop e mobile das interações principais
