- `npm run quality`: aprovado.

- Axe: nenhuma violação séria ou crítica.
- `npm run build:sites`: aprovado.
- `npm audit --omit=dev`: zero vulnerabilidades em produção.
- `npm run capture:qa`: 14 capturas desktop, 14 mobile, vídeo e trace aprovados.

- Branch colaborativa do OmniChat `frontend-hauan`: existência confirmada no repositório de Hauan Felipe.
- Actions oficiais atualizadas para `checkout@v7`, `setup-node@v7`, `upload-pages-artifact@v5` e `deploy-pages@v5`.

## Limitação conhecida da ferramenta Sites

O `npm audit` completo ainda reporta duas vulnerabilidades altas transitivas em `image-size`, dependência exclusiva do Vinext 0.0.50. A correção oferecida pelo npm exige o Vinext 1.0.0-beta.8; essa versão foi testada e descartada porque encerra o `build:sites` com falha nativa de `libuv` no Windows e classifica `/en` como rota desconhecida. A versão estável foi preservada porque:

- o código publicado no GitHub Pages não utiliza Vinext nem `image-size` em produção;
- `npm audit --omit=dev` permanece com zero vulnerabilidades;
- o build Sites estável termina com código zero e pré-renderiza `/` e `/en`;
- as demais correções disponíveis de React, RSC, Cloudflare, Vite, Wrangler, `fast-uri` e `js-yaml` foram aplicadas.
