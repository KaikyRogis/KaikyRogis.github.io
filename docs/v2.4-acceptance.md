# Portfólio 2.4 — matriz de aceite

| Área             | Critério                                                                            | Validação                                 |
| ---------------- | ----------------------------------------------------------------------------------- | ----------------------------------------- |
| Barra mobile     | Controles unificados, área segura e ocultação no contato/rodapé                     | Playwright + inspeção visual              |
| Galerias         | Evidência principal ausente da galeria visível e presente no lightbox               | Playwright                                |
| Trilho mobile    | Fluxo natural, sem pinagem, com `scroll-snap` e indicação de deslize                | Playwright visual                         |
| Evidências       | Altura limitada e moldura derivada da cor do projeto                                | snapshots                                 |

| Responsividade   | Sem overflow em 360×800, 390×844, 430×932, 768×1024, 1366×768, 1440×900 e 1920×1080 | Playwright                                |

| Qualidade        | Prettier, TypeScript, ESLint, links, imagens e builds aprovados                     | `npm run quality` e `npm run build:sites` |

## Comandos oficiais

```bash
npm ci
npm run quality
npm run test:visual
npm run build:sites
npm audit --omit=dev
```
