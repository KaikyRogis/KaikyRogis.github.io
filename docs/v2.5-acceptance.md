# Portfólio 2.5 — matriz de aceite

## Objetivo

Validar que a nova camada cinematográfica acrescenta profundidade e continuidade sem reduzir legibilidade, acessibilidade, desempenho potencial ou previsibilidade da navegação.

| Área          | Critério                                                                                  | Validação                              |
| ------------- | ----------------------------------------------------------------------------------------- | -------------------------------------- |
| Hero          | Profundidade sutil em ponteiro preciso, sem deslocar CTAs no mobile                       | Playwright e inspeção visual           |
| Trilho        | Card central recebe foco espacial e a cor ambiente acompanha o projeto                    | Playwright e snapshots                 |
| Continuidade  | Abrir um projeto leva ao case correto com transição progressiva e fallback funcional      | Playwright                             |
| Evidências    | Capturas reais surgem progressivamente e permanecem acessíveis                            | Playwright e teclado                   |
| Galeria       | Evidência ampla, miniaturas navegáveis e nenhuma imagem cortada por CSS                   | Playwright e inspeção visual           |
| OminiSafety   | Dashboard, empresas e catálogo recapturados integralmente com dados demonstrativos        | Capture QA e inspeção dos ativos       |
| React         | Nenhum aviso de chave ausente em PT ou EN                                                 | Console do servidor de desenvolvimento |
| Movimento     | Modo Profissional, controle manual e preferência reduzida removem movimento não essencial | Playwright                             |
| Mobile        | Sem tilt, pinagem adicional ou overflow horizontal indevido                               | Sete resoluções oficiais               |
| Conteúdo      | Nenhuma informação profissional ou status de projeto é alterado                           | Diff e testes factuais existentes      |
| Versionamento | Pacote, rodapé, terminal, monitor, Capture QA e README identificam 2.5                    | Busca automatizada                     |
| Qualidade     | Prettier, TypeScript, ESLint, imagens, builds e links aprovados                           | Comandos oficiais                      |
| Publicação    | Alteração permanece em pull request até aprovação explícita                               | Branch dedicada e PR                   |

## Comandos oficiais

```bash
npm ci
npm run quality
npm run test:visual
npm run capture:qa
npm run build:sites
npm audit --omit=dev
```

## Resultado da validação

- `npm run quality` aprovado: Prettier, TypeScript, ESLint, orçamento de imagens, build estático e links internos.
- 21 testes Playwright aprovados nas sete resoluções oficiais, incluindo troca da evidência selecionada e verificação de `object-fit: contain`.
- Português e inglês, modos Experiência e Profissional, movimento reduzido, controle manual, zoom de 125%, menu, lightbox, contato e rodapé sem regressão.
- Axe sem violações sérias ou críticas.
- Capture QA aprovado com 14 imagens desktop, 14 mobile, manifesto, vídeo WebM e trace Playwright, sem duplicatas perceptuais.
- Três snapshots desktop do trilho atualizados e revisados; snapshots mobile permaneceram inalterados.
- Dashboard, gestão de empresas e catálogo EHS da OminiSafety recapturados integralmente em 1920 px, com nomes demonstrativos e sem controles internos do preview.
- Build Sites aprovado com três rotas pré-renderizadas.
- Auditoria das dependências de produção com zero vulnerabilidades após sincronização do pacote transitivo `nanoid` em `3.3.18`.
- Branch de backup remoto e ZIP local da versão 2.4.2 confirmados antes da implementação.
- Publicação pendente: a versão permanece na branch dedicada até revisão e aprovação explícita do pull request.
