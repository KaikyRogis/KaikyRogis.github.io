# Portfólio 2.4.2 — matriz de aceite

## Objetivo

Corrigir a trajetória profissional do portfólio com base no currículo atualizado, preservando somente informações confirmadas e mantendo consistência entre o conteúdo público, o código e a release.

| Área               | Critério                                                                                     | Validação                                       |
| ------------------ | -------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| Conteúdo PT        | A experiência não confirmada na RB1/RB4 Inox não aparece na trajetória                       | Playwright dedicado + busca no código publicado |
| Conteúdo EN        | A tradução não apresenta RB1, RB4 ou Inox                                                    | Playwright dedicado + busca no código publicado |
| Texto complementar | Permanecem apenas SAP, Tasy, Ronda e trabalhos administrativos, tecnológicos e independentes | Conferência contra as fontes confirmadas        |
| Regressão          | O teste falha se RB1, RB4 ou Inox voltarem à seção de experiência                            | Playwright em `/` e `/en/`                      |
| Versionamento      | Pacote, rodapé, terminal, monitor, Capture QA e README identificam 2.4.2                     | Busca automatizada e inspeção do build          |
| Qualidade          | Prettier, TypeScript, ESLint, imagens, build e links aprovados                               | `npm run quality`                               |
| Interface          | Sete resoluções, PT/EN, modos e acessibilidade permanecem sem regressão                      | `npm run test:visual`                           |
| Publicação         | Alteração permanece em pull request até a revisão final                                      | PR #5                                           |

## Comandos oficiais

```bash
npm ci
npm run quality
npm run test:visual
npm run build:sites
npm audit --omit=dev
```

## Resultado esperado

- nenhuma referência a RB1, RB4, Inox ou projetos sociais no conteúdo publicado;
- texto complementar consistente em português e inglês;
- `PORTFOLIO VERSION 2.4.2` no site público após o merge e o deploy;
- release futura `v2.4.2` vinculada ao commit publicado;
- tag e release `v2.4.1` preservadas como registro histórico imutável.

## Resultado da validação

- Prettier aprovado nos arquivos alterados.
- TypeScript, ESLint, orçamento de imagens, build do GitHub Pages e links internos aprovados.
- Build Sites aprovado com três rotas pré-renderizadas.
- 18 testes Playwright aprovados nas sete resoluções oficiais.
- PT/EN, Experiência/Profissional, movimento reduzido, zoom de 125%, menu, lightbox, contato e rodapé sem regressão.
- Axe sem violações sérias ou críticas.
- Auditoria das dependências de produção com zero vulnerabilidades.
