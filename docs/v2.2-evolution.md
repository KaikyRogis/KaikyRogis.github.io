# Portfolio evolution — version 2.2

## Delivered

- Complete English route at `/en/`, including interface copy, dialogs, terminal,
  form, project narratives, accessibility labels and route-specific metadata.
- Bidirectional language navigation on desktop and mobile.
- `hreflang`, canonical links and sitemap entries for Portuguese and English.
- Package version aligned to `2.1.0`.
- MIT source-code license separated from the protected-content license.
- Daily GitHub Actions monitoring for build quality, internal links and public
  availability of both languages, `robots.txt` and `sitemap.xml`.

## Evidence policy

New projects and quantitative impact metrics are added only when a public or
user-authorized source proves them. The current release preserves honest status
labels for work in development and does not invent adoption, savings, error
reduction or user counts.

## Required evidence for a future case

- project name, current status and public link or screenshots;
- problem, contribution and technologies actually used;
- metric definition, measured period and authorized value;
- confirmation that company/client information may be published.
